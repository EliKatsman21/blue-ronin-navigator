# Blue Ronin Navigator

נביגטור רכיבה לצפון: אפליקציית ווב (PWA) עם שרת קטן ב־Netlify להתראות ולדיווחי רוכבים.

## איך עובדים מעכשיו: עדכונים בלי להעלות מחדש
האתר ב־Netlify מחובר לריפו הזה ב־GitHub. כל שינוי שנדחף לריפו עולה לאוויר לבד תוך כדקה, באותו קישור.
האפליקציה בודקת גרסה חדשה בכל פתיחה ומתעדכנת לבד, גם אצל מי שהתקין אותה למסך הבית.

### חיבור חד־פעמי
1. ב־GitHub: יוצרים ריפו ריק בשם `blue-ronin-navigator` (פרטי זה בסדר).
2. מעלים אליו את התיקייה הזו. Claude יכול לדחוף אותה בשבילך.
3. ב־Netlify, באתר הקיים: Site configuration ← Build & deploy ← Continuous deployment ← Link repository ← GitHub ← בוחרים את הריפו.
   ההגדרות נקראות לבד מ־`netlify.toml`. לא צריך להגדיר מפתחות או משתני סביבה.

## מבנה
- `site/`: האפליקציה עצמה (index.html, app.js, logic.js, data.js, sw.js, אייקונים)
- `netlify/functions/`: השרת
  - `vapid`, `subscribe`, `test-push`: הרשמה להתראות. מפתחות ההצפנה נוצרים לבד בפעם הראשונה ונשמרים ב־Netlify Blobs.
  - `brief-friday`: תדריך שבת לכל המנויים, בשישי 16:30 בחורף ו־17:30 בקיץ.
  - `brief-saturday`: עדכון בוקר שבת, 05:15 בחורף ו־06:15 בקיץ.
  - `brief`: אותו תדריך כ־JSON (`/api/brief`), לבדיקה.
  - `fuel`: דיווחי רוכבים על תחנות דלק: פתוח בשבת, ויש 98 או אין.
- `netlify.toml`, `package.json`: הגדרות פריסה.

## פרקים
1. כרמל וגלבוע · 2. כנרת וגולן · 3. גליל עליון ועד הים
4. הטבעת הצפונית המלאה: שלושת הפרקים ברצף (`combo` ב־data.js; מזג האוויר מאוחד מהפרקים שבו)
5. נס הרים ובית גוברין: לולאה מאשתאול דרך 38, הסיבובים של 35, עליית 3866, ירידת 386, וחזרה ב־395 (אזור `center`)

רמת הקושי (1 עד 5) מחושבת במכשיר מהמסלול עצמו: צפיפות עיקולים, טיפוס, שיפוע, אורך, ומקדם `tech` לכל פרק (צר, בלי שוליים, תנועה).

6. בקעת הירדן ועליית פצאל: כביש 90 מבית שאן לצפון ים המלח, 505 למעלה אפרים, וחזרה בדרך אלון (508/578) למחולה (אזור `valley`)

## שירותים חיים (מפתחות ב־Netlify, Environment variables, בתחום Functions)
- `TOMTOM_KEY`: תנועה חיה (שכבת מפה ועומסים לאורך המסלול). חינמי ב־developer.tomtom.com.
- `MAPILLARY_TOKEN`: תמונות רחוב של תחנות ובתי קפה. חינמי ב־mapillary.com/dashboard/developers.
בלי המפתחות האפליקציה עובדת, עם תמונות מ־Wikimedia Commons וקישור למפת התנועה של Waze.

## הקו הירוק
`site/geo.js`: מתאר יהודה ושומרון מ־Natural Earth (נחלת הכלל), מפושט לכ־150 מ׳. משמש להתראות כניסה ויציאה מהשטחים.

## צליל הפתיחה
`site/sounds/ignition.mp3`: סינתזה של מנוע תלת־צילינדרי, מתוזמנת למחוג הסל״ד בפתיח. אפשר להחליף בהקלטה אמיתית באורך כ־2.8 שניות: עד 0.25 שנ׳ הנעה, הגז עולה עד 0.9 שנ׳ ויורד עד 1.75 שנ׳.

## עריכת התוכן
מסלולים, עצירות, בתי קפה וקטעי אכיפה נמצאים ב־`site/data.js`. אחרי שינוי עצירות, מעלים את המספר `route:v4` ב־`site/app.js` כדי שהמסלולים יחושבו מחדש אצל כולם.

## התראות
- אנדרואיד ומחשב: לשונית ״כלים״ ← ״הפעלת התראות״.
- אייפון (iOS 16.4 ומעלה): קודם ״הוספה למסך הבית״, פותחים מהאייקון, ואז מפעילים.

## מקורות נתונים
מפה: OpenFreeMap ו־OpenStreetMap (ODbL). תחנות דלק, שעות וסוגי דלק: OpenStreetMap, ואימות רוכבים בתוך האפליקציה. מזג אוויר וגבהים: Open-Meteo (CC BY 4.0). מכ״ם: RainViewer. ניתוב: OSRM. תבליט: Mapzen / AWS.

## ממשק ניהול (`/admin.html`)
כניסה עם סיסמה וקוד מאפליקציית אימות (TOTP). דרכו משנים בלי קוד: הודעה בראש האפליקציה, מצב תחזוקה, התראה לכל הטלפונים, הסתרת פרקים והתראות פרק, המסלול המומלץ, עריכת טקסט העצירות, מפגעים על המפה (עם התראה קולית במצב רכיבה), תיבת דיווחי רוכבים, איפוס סימוני דלק, מתגי פיצ׳רים, החלפת סיסמה, ניתוק כל ההתחברויות ויומן פעולות.
- הקמה ראשונה: משתנה סביבה `ADMIN_SETUP_CODE` ב־Netlify. הקוד עובד רק כל עוד אין מנהל.
- שחזור (טלפון אבד): מגדירים `ADMIN_RESET_CODE`, פורסים, נכנסים ל־`/admin.html#reset`, ואז מוחקים את המשתנה.
- השרת: `netlify/functions/admin.mjs` ו־`lib/admin.mjs`. התוכן הציבורי: `/api/content`. משוב: `/api/feedback`. ספירה יומית אנונימית: `/api/ping`.
- אבטחה: סיסמה ב־scrypt, אימות דו־שלבי עם הגנה מפני שימוש חוזר בקוד, עוגייה חתומה (HttpOnly, Secure, SameSite=Strict) לנתיב `/api/admin` בלבד, כותרת ייעודית ובדיקת Origin בכל כתיבה, חסימה אחרי 5 ניסיונות ב־15 דקות, ו־CSP קשיח לעמוד הניהול.

## אבטחה כללית
כותרות ב־`netlify.toml`: CSP (סקריפטים רק מהאתר, unpkg ו־cdnjs), HSTS, X-Frame-Options, Permissions-Policy. אין סקריפטים מוטבעים ב־HTML (הפתיח ב־`intro.js`).
